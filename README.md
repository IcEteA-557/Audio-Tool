# 音频互联

把一台 Mac 的系统混音，用未压缩音频送到同一局域网里的 Windows 11 播放。两端是同一个程序，角色由系统决定：Mac 采集并发送，Windows 接收并播放。

普通 Type-C 充电线或数据线插在两台电脑之间不会出现网卡，软件也不能把它变成声卡。第一版走同一局域网。界面会把 Thunderbolt Bridge、USB 网卡和 Remote NDIS 标成「有线直连」。以后插上这类网卡并打开「优先有线直连」（默认开启）后，发现、控制和音频都会改走那块网卡。

音频是 48 kHz、立体声、16 bit PCM，走 UDP，不加密、不重传。请只在你信任的局域网里使用。

## 准备环境

Mac 需要 macOS 14.2 或更高、Xcode 命令行工具和 Rust。Windows 11 需要 Rust 的 MSVC 工具链。

两台电脑要在同一个子网。路由器不要开启客户端隔离，否则两台设备互相看不见。建议用 5 GHz Wi-Fi。

## 在 Mac 上运行

```sh
scripts/macos-app.sh
open "dist/音频互联.app"
```

第一次开始发送时，系统会弹出「系统音频录制」授权。请允许 `音频互联`。直接运行 `cargo run` 得到的裸可执行文件没有这份用途说明，系统可能拒绝采集，所以日常使用请打开上面的应用包。

窗口里可以：

- 看到本机网卡和对端电脑。对端约 3 秒没有信标或控制心跳后标为离线。
- 选中对端后点「连接」。任一侧都可以发起连接。
- 选择目标延迟：15 / 20 / 30 / 50 毫秒，默认 30。Wi-Fi 抖动大时，程序会自动升到能稳住的档位，并在窗口里写明当前实际延迟。
- 「仅在 Windows 播放」会静音被采集的本机输出。
- 「本机试听」把同一条链路送回这台 Mac 的扬声器，用来在没有 Windows 时检查采集和缓冲。打开后会静音原来的扬声器，并排除本程序自己的声音，避免延迟后的声音被再次采集。

菜单栏图标可以显示窗口、静音本机输出，或退出。关掉窗口只是隐藏，退出要从图标菜单里选。

## 在 Windows 11 上运行

```sh
cargo build --release
.\target\release\audiolink.exe
```

第一次运行时，允许专用网络上的防火墙入站：UDP 47611（发现）、TCP 47612（控制），以及程序临时使用的 UDP 音频端口。播放设备在 Windows 窗口里选择，选择会被记住。设备被拔掉时会退回默认设备，并在窗口里说明。

## 延迟

默认目标大约 30 毫秒，可调 15 / 20 / 30 / 50。每个音频包约 5 毫秒，丢了就用上一帧衰减后顶上，不重传。接收端按缓冲水位做大约 ±0.1% 的变速，避免两台电脑晶振慢慢漂开。控制通道大约每 200 毫秒测一次往返，用来估算延迟。

Wi-Fi 干扰大时，20 毫秒一档会经常欠载，程序会自动放宽。这是网络抖动的限制。换成有线直连后更容易停在较低的一档。

## 以后换成网线或雷电

插上 USB 网卡、雷电线，或出现 Remote NDIS 后，网卡表里会多一行「有线直连」。保持「优先有线直连」开启即可，不用改协议。那块网卡需要已经拿到 IPv4 地址。
